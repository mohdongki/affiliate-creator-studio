# 10 AI Agent — alur kerja

1. Manager Agent — mengatur prioritas, kelengkapan data, dan urutan pekerjaan.
2. Product Research Agent — memeriksa manfaat, harga, ulasan, bukti klaim, dan potensi produk.
3. Audience Research Agent — merumuskan segmen, kebutuhan, keberatan, dan bahasa audiens.
4. Content Strategist Agent — menyusun pilar konten dan eksperimen angle.
5. Script Writer Agent — menyusun naskah video pendek.
6. Hook & Copywriter Agent — menyiapkan hook, caption, dan CTA.
7. Video Planner Agent — membuat urutan shot dan teks layar.
8. SEO & Hashtag Agent — menyarankan kata kunci dan hashtag.
9. Publishing Agent — menyediakan checklist publikasi.
10. Analytics Agent — membantu membaca metrik yang dimasukkan manual.
